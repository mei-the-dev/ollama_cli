## 🐛 Convergence Troubleshooting

### Autocomplete Not Converging

```bash
# Check convergence dependencies
pip install prompt_toolkit

# Clear convergence cache
rm -rf ~/.singularity/cache
```

### Slow Convergence

```bash
# Rebuild convergence index
singularity> /reindex

# Reduce context in config
{
  "context": {
    "max_nodes": 3,
    "cache_ttl": 60
  }
}
```

### Convergence Server Not Starting

```bash
# Check convergence logs
tail -f ~/.singularity/logs/singularity.log

# Restart convergence engine manually
python ~/.singularity/mcp_server.py --port 8000
```
