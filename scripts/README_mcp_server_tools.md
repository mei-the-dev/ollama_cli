# MCP-server Tools & Resources

## Overview
This directory contains:
- mcp_prompt_template.py: Prompt template for code generation
- mcp_server_tools.py: Utility functions for validation, extraction, error taxonomy, event logging, post-processing
- mcp_server_resources.md: Documentation of workflow, error handling, and integration
- mcp_server_update_log.md: Change log for MCP-server updates

## Usage
- Always use mcp_prompt_template.py for prompt engineering
- Integrate mcp_server_tools.py for all validation and post-processing
- Follow workflow in mcp_server_resources.md
- Review changes in mcp_server_update_log.md
